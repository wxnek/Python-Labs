Лабораторная работа №9, вариант 2 — «Калькулятор»

Файлы:
models.py       — класс Calculation (dataclass)
exceptions.py   — собственные исключения
repository.py   — хранение расчётов в памяти
service.py      — бизнес-логика и вычисления
protocol.py     — JSON-протокол
server.py       — TCP-сервер
client.py       — консольный TCP-клиент
tests/          — автоматические тесты

Запуск:
1. Открыть терминал №1 и перейти в папку проекта:
   cd путь\к\lab9_variant2

2. Запустить сервер:
   python server.py

3. Открыть терминал №2, перейти в ту же папку и запустить клиент:
   python client.py

Тесты:
   python -m unittest discover -s tests -v

Стороны взаимодействуют по TCP через 127.0.0.1:5000.
Протокол использует JSON Lines: каждое сообщение заканчивается символом '\n'.

В меню клиента:
1 — список расчётов
2 — получить расчёт по ID
3 — создать расчёт
4 — изменить расчёт
5 — удалить расчёт
6 — вычислить выражение
7 — проверить тайм-аут
0 — выход

Исправление по сравнению с исходной версией:
клиент отдельно разбирает JSON-ответ сервера и больше не требует от ответа полей command/data.
